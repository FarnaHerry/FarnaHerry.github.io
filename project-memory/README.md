# FarnaHerry.github.io 项目共享记忆

本目录存放团队与 AI Agent 跨会话复用的稳定事实，与 `AGENTS.md`（唯一约束规范）和 `project-skills/`（按需操作手册）职责分离。

## 文件索引

| 文件 | 记录内容 | 何时阅读 |
| --- | --- | --- |
| [architecture.md](architecture.md) | 集合架构、样式与主题流水线、双图/导航栏交互及 SEO/部署管线 | 理解整体架构、改动页面容器归属或修改布局/导航交互前 |
| [decisions.md](decisions.md) | 已落地的架构决策（ADR）与原因背景 | 疑问为何采用当前技术方案、计划推翻或替代既有机制前 |
| [pitfalls.md](pitfalls.md) | 已实测定位的样式/组件/集合/CI 坑点与解决方式 | 遇到主题切屏异常、链接样式覆盖、CI 报错或修改相邻模板前 |

## 维护原则

1. **只记已验证事实**：仅记录直接观测或实测确认的文件路径、选择器、行为与根因，不写猜测与未落地设想。
2. **增量精炼、去重更新**：新方案替代旧方案时同步更新或删除过期条目，避免冲突信息留存。
3. **职责不越界**：硬性工程红线留在 `AGENTS.md`，可复用操作步骤写入 `project-skills/`，本目录只沉淀“现状、决策依据与坑点”。
